# Bespoke Vista — website

Static marketing site for Bespoke Vista Ltd. *Bridging Strategy and Execution.*

Pages: Home, About, Services (with packaged engagements), Case Studies, Insights, Contact.

## Structure

```
index.html, about.html, services.html, case-studies.html, insights.html, contact.html
assets/css/styles.css   all styling (brand colours are CSS variables at the top)
assets/js/main.js       mobile menu, scroll reveal, contact form
assets/img/logo-mark.svg  BV monogram in a viewpoint/window frame (also the favicon)
build.py                generates the HTML pages
```

The HTML pages are generated by `build.py` so the header, footer and repeated
content stay consistent. Edit content in `build.py`, then run:

```
python3 build.py
```

No build step is needed to host the site: upload the folder to any static host
(GitHub Pages, Netlify, Cloudflare Pages or a standard web server).

## Before going live

- **Email address**: `hello@bespokevista.co.uk` is a placeholder. Set `CONTACT_EMAIL` in `build.py` and rebuild.
- **Contact form**: without configuration it opens the visitor's email client with the message filled in.
  To receive submissions directly, create a form endpoint (e.g. Formspree) and put its URL in the
  form's `data-endpoint` attribute in `build.py`.
- **Company details**: add the company registration number and registered office to the footer if required.
- **LinkedIn**: add a link to the LinkedIn profile/company page in the footer and contact page.
- **Founder photo**: the About page uses an "AM" monogram; swap in a professional headshot if preferred.
- **Pricing**: package prices on the Services page are indicative; confirm before publishing.
